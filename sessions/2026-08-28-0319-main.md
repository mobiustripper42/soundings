**Completed:**
- `contracts/firmware-manifest-v2.md` — new spec; `sig` required, the canonical signed
  message pinned, key handling and the transition written down. v1 marked superseded and
  otherwise untouched, because a new *required* field is exactly what v1's own rule 3
  says needs a version bump rather than an amendment.
- `firmware/src/core/ed25519.{h,cpp}` — vendored TweetNaCl verify (public domain), one
  deliberate deviation (`gf0 = {0}`, C++ const-init). Verifies only; no signing on the
  node. **7,232 bytes of image.**
- `firmware/src/core/fw_manifest.{h,cpp}` — `sig` parsed as 128 lowercase hex,
  `canonicalMessage()` rebuilds the four fields in fixed order from parsed values,
  `verifyManifest()`.
- `firmware/src/esp32/ota_client.cpp` — `SOUNDINGS_OTA_PUBKEY` decoded from hex, checked
  before the radio comes on; signature verified before the image is requested at all.

  `[ota]` section that `node_secret.ini` can blank. `kFwVersion` 262 → 263 in
  `firmware/src/esp32/main.cpp`.
- `gateway/soundings_gateway/ota.py` — parse + verify; `UpdatePolicy` requires a 32-byte
  key with no None escape and refuses to flag an unverified manifest.

  overwrite), `--key` required, signs before the atomic rename.

- `contracts/vectors/manifest-sig-v1.json` + `contracts/tools/gen_sig_vectors.py` — 12
  shared vectors grading all three implementations; the test key is published on purpose

  `.gitignore` (`*ota-signing-key*`), `gateway/pyproject.toml` (`cryptography>=41`).
